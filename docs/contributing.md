## How to Propose a Change

1. Open an issue describing what you want to change and why.
2. Wait for feedback before writing code — this avoids wasted effort.
3. Fork the repository and create a feature branch: `git checkout -b feature/your-feature-name`.
4. Make your changes, following the coding standards above.
5. Open a pull request against `main` with a clear description of what changed and why.

---

## How to Report a Bug or Error

Please open a GitHub issue and include:

- A short, descriptive title
- Steps to reproduce the problem
- What you expected to happen vs. what actually happened
- Any relevant logs, error messages, or screenshots
- The version or commit hash you were using
